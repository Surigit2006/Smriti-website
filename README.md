# Smriti Notes — Landing Page

> **Your thoughts deserve a better space.**  
> A beautiful notebook for writing, planning, sketching, and connecting ideas — designed around the way you think.

---

## 🌟 Highlights & Layout Strategy

This landing page follows the exact strategic design direction:
1. **Visual Hook — 162 Color Palettes**:
   - Interactive palette browser across categories (Paper & Editorial, Minimalist, Pastel & Calm, Cyber & Dark, Earthy & Forest, Sunset & Vibrant).
   - Real-time page recoloring upon clicking any palette.
   - Interactive Pen Color & Hex Code studio (referencing pen colors with hex codes).
2. **Main Product Benefit — Premium Note Editor**:
   - Streamlined, non-tabbed spatial layout.
   - Live interactive Markdown & rich-text editor with instant word count, reading time, and formatting controls.
   - Clean desktop notebook aesthetic inspired by Serhii Yermolenko's design.
3. **Current Feature — Effortless Organization**:
   - Folders, Pinned notes, Archive, Trash, and instant `⌘K` fuzzy search dialog simulator.
   - Offline-first JSON export/import actions.
4. **Signature Upcoming Feature — Connected Sticky Notes**:
   - Interactive visual 2D canvas with nodes connected via relational SVG curves.
   - Bridges messy brainstorming to long-form structured notes (inspired by Heptabase knowledge mapping).
5. **Dedicated Roadmap Section ("More than a place to take notes")**:
   - Clearly separated upcoming features with status badges and upvoting:
     - ☁️ **Cloud Sync**: End-to-end encrypted multi-device sync
     - 📑 **Ready-to-use Templates**: Student timetables, daily planners, and project trackers
     - ✏️ **Sketching and Freehand Drawing**: Infinite flexible vector ink
     - 🤖 **AI-Powered Productivity**: Summarize notes and generate study materials
6. **Conversion & Community**:
   - Interactive Early Access Modal with celebratory confetti and queue position.
   - Comprehensive FAQ addressing why Smriti abandoned tab overload.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
